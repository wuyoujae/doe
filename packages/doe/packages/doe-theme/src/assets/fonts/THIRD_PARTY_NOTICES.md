## MiSans

Yrkie DOE uses the unmodified MiSans variable font for browser rendering and the Light, Medium, and Semibold webfont files for editable presentation embedding. Regular and Bold remain bundled for compatibility with earlier DOE exports.

- Copyright and licensor: Xiaomi Inc.
- Official project: https://hyperos.mi.com/font/en/

## EB Garamond and IBM Plex Mono

DOE bundles unmodified Latin WOFF2 faces (400 and 600, normal and italic) from the locally installed Fontsource packages. EB Garamond supplies Atelier headings; IBM Plex Mono supplies code in the four new themes. MiSans remains the Chinese fallback.

- EB Garamond: Copyright 2017 The EB Garamond Project Authors; SIL Open Font License 1.1; bundled `eb-garamond/OFL.txt`.
- IBM Plex Mono: Copyright 2017 IBM Corp.; SIL Open Font License 1.1; bundled `ibm-plex-mono/OFL.txt`.
- Assets are owned by DOE and served locally for Canvas, Studio, share and export; no runtime Fontsource or remote-font dependency.

## Fredoka and Caveat

DOE bundles the unmodified variable TTFs and OFL files from the Google Fonts repository, downloaded on 2026-10-08. These are the actual rounded and handwritten fonts used by Sunburst and Coast; they are not claimed to be Gamma's font selections.

- Fredoka: https://github.com/google/fonts/tree/main/ofl/fredoka; SIL Open Font License 1.1; bundled `fredoka/OFL.txt`; weight 300–700, width 75–125 (default width retained).
- Caveat: https://github.com/google/fonts/tree/main/ofl/caveat; SIL Open Font License 1.1; bundled `caveat/OFL.txt`; weight 400–700.
- Browser and PPTX use the same local sources; Chinese headings use the existing MiSans fallback.
